# Simple Blog CMS with Admin Panel

A basic blog content management system with user authentication.

## Features

* User registration and login
* Post creation, editing, and deletion
* Dashboard to view all posts

## Setup/Run Instructions

1. Clone the repository: `git clone https://github.com/your-username/simple-blog-cms.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`

## What I Learned

I learned how to create a simple blog CMS with user authentication using Flask and SQLAlchemy. This project helped me understand the importance of database management, user security, and routing in web development. It also taught me how to use Flask-Login for user authentication and Werkzeug for password hashing.
